# Sentiment Analysis using Machine Learning

  A Machine Learning project that uses **Natural Language Processing (NLP)** to analyze text reviews and predict their sentiment.

##  Features

* 📝 Text review analysis
* 🤖 Sentiment prediction using **Support Vector Machine (SVM)**
* 🔍 Text feature extraction using **TF-IDF**
* 🌐 Interactive web interface using **Streamlit**

## Tech Stack

`Python` · `NLP` · `Scikit-learn` · `NLTK` · `Pandas` · `Streamlit`

##  How It Works

**Text Input → Preprocessing → TF-IDF → SVM Model → Sentiment Prediction**

##  Run Locally

```bash
git clone https://github.com/GaganNagesh/Sentiment-Analysis.git
cd Sentiment-Analysis
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m streamlit run app.py
```
